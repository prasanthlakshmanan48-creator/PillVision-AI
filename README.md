# 💊 PillVision AI

An AI-powered medicine recognition system built using Streamlit, Google Gemini AI, OCR and Python.

---

## Features

✅ Scan Medicine

✅ OCR Text Detection

✅ AI Medicine Search

✅ Drug Interaction Checker

✅ AI Health Chat

✅ PDF Report

✅ Scan History

---

## Technologies

Python

Streamlit

Gemini AI

EasyOCR

ReportLab

NumPy

Pillow
